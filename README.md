# Тёплый угол — сайт кофейни

Демонстрационный проект для портфолио. Кофейня вымышленная.

Светлый адаптивный сайт на HTML, CSS и JavaScript без зависимостей и сборки.

## Возможности

- 16 позиций в четырёх категориях меню; цены в тенге.
- Переключение категорий и подробности с составом и аллергенами.
- Мобильная навигация, FAQ, галерея и плавные переходы.
- Мягкие CSS-анимации с поддержкой prefers-reduced-motion.
- Управление с клавиатуры и нативное диалоговое окно.
- Фотографии сохранены локально; источники — ASSETS.md.

Заказы, оплата, бронирование, аналитика и сбор персональных данных отсутствуют. Контакты и часы работы — демонстрационные.

## Запуск

Откройте index.html в современном браузере. Устанавливать пакеты не нужно.

## Редактирование

- app.js — объект menu: названия, описания, цены, состав и аллергены.
- index.html — тексты, история, FAQ, секция contacts с адресом и часами работы.
- assets/ — фотографии. При замене меняйте описания alt.
- styles.css — цвета, размеры, адаптивная вёрстка и анимации.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save. После успешного развёртывания GitHub покажет адрес сайта. Последующие коммиты в main будут обновлять сайт автоматически.

## Проверки

Локально проверены мобильная навигация, переключение категорий, подробности капучино, закрытие Escape, FAQ и загрузка изображений. На ширинах 320 и 390 px горизонтального переполнения не обнаружено. Физический телефон и FPS не проверялись.
